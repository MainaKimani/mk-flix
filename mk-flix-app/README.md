# 🎬 MK-Flix — Android app

Android client for [cinejoy.pk](https://cinejoy.pk/): a fullscreen WebView
with ad blocking, MK-Flix branding and a proper error screen.

- Package: `com.w2a.um1c` (kept from CineJoy; changing it would make Android
  treat MK-Flix as a different app)
- Version: 1.4.0 (versionCode 140), set in `app/build.gradle.kts`
- Android 7.0 (API 24) and newer; targets and compiles against API 34

## What's where

All the app's code is in `app/src/main/java/com/w2a/um1c/MainActivity.java`:

- **WebView setup** and the **ad blocker** (requests to hosts in
  `assets/adblock-hosts.txt` get a 404, subdomains included)
- **Fullscreen video**: landscape while playing, then back to the
  orientation you had; Back leaves fullscreen first
- **Downloads** through Android's DownloadManager, with the page's cookies
  so signed-in downloads work; asks for storage permission on Android 7–9
- **Navigation**, matching the desktop app: only cinejoy.pk loads in the
  app; a tapped YouTube or Vimeo link opens in its app or the browser;
  anything else off-site is dropped. Embedded players aren't affected.
- **Links to other apps** (`tel:`, Play Store, `intent:`): only from a real
  tap, never for intents that just open a web page in a browser (how ads
  escape to Chrome), and limited to what a browser may open, so a web page
  can't launch arbitrary parts of other apps
- **Click-catchers**: ad networks' transparent full-screen overlays (top
  z-index, added after load) are made to let touches through, so swipes and
  taps reach the page
- **Android TV / Google TV**: the same APK, detected at runtime (UI mode
  television); phones are unaffected. The manifest adds a TV launcher entry
  and banner (`res/drawable-*/tv_banner.png`, generated by
  `branding/make-icons.py`) and doesn't require a touchscreen. On a TV:
  - `assets/mkflix-tv.js` lays the site out 1280px wide (its desktop layout
    with the top menu, instead of the tablet layout with a floating bottom
    menu), moves a neon highlight with the arrow keys (rows scroll to follow
    it; left/right stay within a row), opens the highlighted item with OK,
    and on video pages makes OK play/pause and left/right skip 10 s while the
    video is highlighted. The remote's media keys work wherever there's a
    video.
  - Pointer mode (`TvPointer` in MainActivity): hold OK to toggle an
    on-screen pointer moved by the arrows; OK taps under it, pushing past a
    screen edge scrolls by a third of the screen, Back turns it off.
  - The screen stays on while on a video page.
- **Branding**: `assets/mkflix-logo.css` draws the MK-Flix mark in place of
  the site's logos (header and video loading screen), added as soon as each
  page is about to show; `assets/mkflix-footer.js` replaces the site's footer
  once the page has loaded
- **Error screen**: `assets/error.html` replaces a page that fails to load,
  explains why (offline, network blocking the site, connection failed) and
  offers Retry. Certificate failures count only for the page being opened,
  so a blocked image or ad can't replace a working page. Back from the error
  screen returns to the last page that worked.

`error.html`, `mkflix-footer.js`, `mkflix-logo.css` and `adblock-hosts.txt`
are shared with the desktop app and must stay identical to the copies in
`../mk-flix-desktop/`. The icons, `mkflix-logo.css` and `assets/icon.png`
are generated by `../branding/make-icons.py`.

## Building

### Android Studio

Open this folder (`mk-flix-app/`) and press Run. Android Studio provides the
SDK, Gradle 8.7 and a suitable Java (21).

### Command line

Needs the Android SDK (`ANDROID_HOME`), Java 17 or 21 (Gradle 8.7 doesn't run
on newer Java), and Gradle 8.7. There's no `gradlew` in the repo; run
`gradle wrapper --gradle-version 8.7` once to create it, or use the Gradle
that Android Studio downloads.

```sh
gradle assembleDebug     # app/build/outputs/apk/debug/app-debug.apk
gradle assembleRelease   # app/build/outputs/apk/release/app-release.apk
```

`build-apk.sh` builds a debug APK with the SDK tools directly, without
Gradle. It reads the package name and version from `app/build.gradle.kts`.

### Signed release builds

`assembleRelease` signs with the release key named by these Gradle
properties, normally in `~/.gradle/gradle.properties` on the machine that
publishes releases:

```properties
MKFLIX_RELEASE_STORE_FILE=/path/to/mkflix-release.jks
MKFLIX_RELEASE_STORE_PASSWORD=...
MKFLIX_RELEASE_KEY_ALIAS=mkflix
MKFLIX_RELEASE_KEY_PASSWORD=...
```

The key never goes in this repo. Without these properties a release build
is left unsigned (debug builds are unaffected). **Every release must be
signed with the same key**: Android refuses to install an update signed
with a different one, so losing the key means users must uninstall to
upgrade.

## Testing

Worth checking on two emulators, Android 7.0 (API 24) and Android 14 or
newer:

| Check | Where |
|---|---|
| Name and icon on the home screen (themed icon on 13+) | API 34+ |
| Old-style icon | API 24 |
| MK-Flix logo in the header and on the video loading screen, no flash of the old one; MK-Flix footer | Any |
| Fullscreen video, then Back: no crash | API 24 |
| Rotation works again after leaving fullscreen | Any |
| Download asks for storage permission, then works | API 24 |
| `tel:` and Play Store links open their apps | API 34+ |
| Error screen: turn off Wi-Fi and data, open a page; it retries by itself when you reconnect | Any |

Debug builds allow inspecting the WebView from Chrome's
`chrome://inspect` (or any Chrome DevTools client over `adb forward`).
Release builds don't.

## Installing

Install the APK from the
[latest release](https://github.com/MainaKimani/mk-flix/releases/latest).

**On Android TV / Google TV**, there's no browser to download with, so
either:
- install the free **Downloader** app (by AFTVnews) from the TV's Play Store,
  allow it to install unknown apps when asked, and open the APK's download
  link from the release page in it; or
- from a computer on the same network, with *Developer options → Network
  debugging* (or *USB debugging*) on the TV:
  `adb connect <TV's IP address>` then `adb install MK-Flix_<version>.apk`.

MK-Flix then appears in the TV's **Apps** row.
If the old CineJoy app, or a debug build, is installed, uninstall it first:
they're signed with different keys, so Android won't install over them.
